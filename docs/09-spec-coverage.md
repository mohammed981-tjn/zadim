## بند ٤٨ — المحظورات الاثنا عشر وكيف مُنع كلٌّ منها

| المحظور | ما يمنعه هنا |
|---|---|
| نموذجٌ أوّليّ بسيط | المرحلة ٠ معمارٌ لا واجهة |
| واجهةٌ بلا خادم | [ADR-003](00-decisions.md): **صفرُ منطقٍ في الواجهة** |
| بياناتٌ وهمية في مسارٍ حقيقيّ | بوّابةُ كل مرحلة |
| **قواعدُ عملٍ مبرمَجة** | كلُّها صفوف: `prices` · `tax_rates` · `shipping_rates` · `promotion_rules` · `loyalty_settings` |
| أسعارٌ أو ضرائبُ أو شحنٌ في الكود | نفسه + **grep في CI** |
| تصميمُ القاعدة بعد الواجهة | المخطط أُنجز في المرحلة ٠ ✅ |
| أزرارٌ لا تفعل شيئاً | بوّابةُ كل مرحلة |
| ميزةٌ «مكتملة» بلا اختبار | البوّابةُ تشترط الاختبارات |
| حذفُ ميزةٍ لأنها صعبة | **هذا الجدول** — الستّون كلُّها لها حكم |
| بلا تدقيق | `audit_logs` ✅ **مُختبَر** |
| بلا ضبطٍ إداريّ | كلُّ قاعدةٍ صفٌّ يضبطه المدير |
| بلا تصميمٍ للتوسّع | تعدّدُ القنوات والمواقع والبائعين من اليوم |

## ما أُعدِّل من مواصفتك — بندان لا غير، وبحجّة

**١. بند ١١ — آلة الحالات.** عمودٌ واحد بستّ عشرة حالة **يخلط ثلاثة
محاور** ولا يستطيع وصف طلبٍ شُحن بعضُه واسترُدّ بعضُه. البرهانُ والحلُّ
وجدولُ التعبير في [`03`](03-state-machines.md) §0. **ولم تسقط حالة.**

**٢. بند ٤١ — الذكاء.** يُؤجَّل كلُّه إلى المرحلة ١٤ (وهو موضعُه في
ترتيبك) لأنه **دوالُّ في سجلٍّ تاريخيّ لا نملكه بعد**. ويبقى في المعمار
نقطةُ ربط.

**وما عدا هذين: مأخوذٌ كما كتبتَه.**
